## Stack technique

Ce portfolio est construit en **HTML / CSS / JavaScript vanilla**, sans framework ni dépendance de build — un seul fichier, facile à héberger sur GitHub Pages.

| Catégorie | Technologies |

| Structure & style | HTML5, CSS3 (variables CSS, Grid, Flexbox) |
| Interactivité | JavaScript (vanilla), Canvas API |
| Typographies | Cormorant Garamond, Outfit, DM Mono (Google Fonts) |

## Lancer le projet en local

Aucune installation n'est nécessaire — c'est un site statique.

```bash
git clone https://github.com/victoria-ngoussi/my_portfolio.git
cd my_portfolio
```

Puis ouvrez simplement `index.html` dans votre navigateur, ou lancez un petit serveur local :

```bash
python3 -m http.server 8000
```

Et rendez-vous sur `http://localhost:8000`.
